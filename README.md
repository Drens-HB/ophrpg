# YORU — actualización visual

Esta versión mantiene el lector, los seis capítulos, los textos y la navegación del proyecto original. Cambia la cabecera para usar un logotipo de pincel recortado de la referencia visual y sustituye los fondos abstractos por ilustraciones sin texto incrustado.

## Archivos
- `index.html` — cabecera actualizada.
- `css/style.css` — tipografías Cinzel + Libre Baskerville, dimensiones más compactas y fondos ilustrados.
- `js/app.js` — se conserva la historia y la navegación.
- `assets/images/` — logotipo y nuevas ilustraciones.

## Probar
Abre `index.html` en un navegador o usa Live Server en VS Code.

## Subir a GitHub
Copia el contenido de esta carpeta sobre la carpeta del proyecto que ya tienes, conservando la estructura `css/`, `js/` y `assets/images/`. Revisa los cambios en Source Control y haz commit/push.

Nota: la ilustración de entrenamiento se reutiliza en varias viñetas como primera pasada visual. Para una versión final, lo ideal es generar escenas independientes para Suiren, la expulsión, el naufragio, Tumi y Yoru Pirates, manteniendo el texto narrativo en HTML.
