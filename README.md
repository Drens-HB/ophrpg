# Yoru — novela gráfica

Versión simplificada para incrustar en ForumCommunity mediante un embed de GitHub Pages.

## Archivos
- `index.html`: lector y selector de capítulos.
- `css/style.css`: diseño del lector de hasta 1000 px de ancho, viñetas y recuadros narrativos.
- `js/app.js`: capítulos, navegación por botones y teclado, transiciones entre páginas.
- `assets/images/referencia-pagina-manga.png`: referencia visual de estilo (no utilizada como página final).

## Publicar
Sube el contenido de esta carpeta a la raíz del repositorio y activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → / (root)**.

## Nota
La versión actual es una maqueta funcional de la estructura y navegación. Las viñetas usan fondos CSS estilizados como marcadores provisionales; el texto narrativo ya está integrado en HTML y puede editarse en `js/app.js`. Sustituye los fondos provisionales por ilustraciones originales cuando estén listas.
